# QuizParty

Run locally:
    npm install
    npm start
Host opens http://localhost:3000/host.html  — players open http://localhost:3000 (or http://<your-LAN-IP>:3000 on the same Wi-Fi) and enter the code.

Edit questions.json to change the quiz (correct = zero-based index of the right option).

Deploy (Render): push to GitHub, create a "Web Service", build command `npm install`, start command `npm start`.
